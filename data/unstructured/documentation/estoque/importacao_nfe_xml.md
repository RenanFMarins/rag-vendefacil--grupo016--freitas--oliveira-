# Manual de Importação de NF-e via XML e Cadastro Automático de Produtos

## 1. Importação de Notas de Fornecedores
1. Acesse o módulo `VendeFácil Estoque -> Compras -> Importar XML`.
2. Faça o upload do arquivo `.XML` recebido da distribuidora ou insira a chave de acesso de 44 dígitos para download direto da SEFAZ via Certificado Digital A1/A3.
3. **Mapeamento de De-Para de Produtos:** Na primeira importação de um novo fornecedor, o sistema solicitará o vínculo entre o código do item no fornecedor e o SKU interno VendeFácil.
4. O sistema calcula automaticamente o custo médio ponderado e sugere o preço de venda com base na margem de lucro (markup) pré-configurada.
